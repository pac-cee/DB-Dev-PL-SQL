# PL/SQL Development Learning Repository

This repository contains comprehensive materials, examples, and exercises for learning PL/SQL (Procedural Language/Structured Query Language) development. The content is structured to provide both fundamental and advanced concepts in database programming with Oracle PL/SQL.

## Repository Structure

### 1. Fundamentals (`01_fundamentals/`)
- **Basic Blocks** (`01_basic_blocks/`): Introduction to PL/SQL block structure
- **Variables** (`02_variables/`): Variable declarations and data types
- **Control Structures** (`03_control_structures/`): Conditional statements and loops
- **SQL in PL/SQL** (`04_sql_in_plsql/`): Integration of SQL within PL/SQL blocks

### 2. Advanced Topics (`02_advanced/`)
- **Procedures and Functions** (`01_procedures_and_functions/`): Creation and usage of stored procedures and functions

### 3. Learning Materials (`Learning_PLSQL/`)
- Basic to advanced PL/SQL concepts
- Practical examples and test scripts
- Database connection scripts
- Window functions examples
- Wallet management examples
- Customer and user management scripts

### 4. Notes and Lectures (`NOTES/`)
Contains comprehensive lecture materials covering:
- Introduction to PL/SQL
- SQL Query Execution
- Stored Procedures
- Collections and Records
- Cursors (Implicit & Explicit)
- Advanced PL/SQL Concepts
- Exam preparation materials
- Capstone project documentation

### 5. Practice Section (`practice/`)
- Advanced exercises
- Employee management system examples
- Test cases and setup scripts

### 6. Assignments
- Individual assignments and solutions
- Capstone project materials
- Practice exercises

## Key Features

1. **Window Functions**: 
   - Comprehensive examples of SQL window functions
   - Ranking, aggregation, and analytical functions
   - Sample data and practical use cases

2. **Database Management**:
   - User and customer management scripts
   - Container management guidelines
   - Wallet application examples

3. **Practical Examples**:
   - Employee management system
   - Customer database operations
   - Advanced PL/SQL implementations

## Learning Path

1. Start with the fundamentals in `01_fundamentals/`
2. Progress through the lectures in `NOTES/`
3. Practice with examples in `Learning_PLSQL/`
4. Complete assignments and exercises
5. Move to advanced topics in `02_advanced/`
6. Work on the capstone project

## Prerequisites

- Oracle Database (recommended version specified in lectures)
- SQL*Plus or Oracle SQL Developer
- Basic understanding of SQL

## Getting Started

1. Review the module description in `NOTES/MODULE DESCRIPTION FORM 3.docx`
2. Follow the lecture materials in sequential order
3. Complete exercises after each lecture
4. Utilize the practice scripts in the `practice/` directory
5. Refer to assignment solutions for guidance

This repository serves as a complete learning resource for PL/SQL development, from basic concepts to advanced implementations, with practical examples and real-world applications.
