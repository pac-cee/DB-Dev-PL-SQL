## 🔍 PART 1: DETAILED EXPLANATION — CURSORS IN PL/SQL

### 🚀 What is a Cursor?

A **cursor** is a pointer to the **context area** created by Oracle to process SQL statements. It allows **row-by-row** handling of results returned by SQL queries.

There are two major types:
- **Implicit Cursor** – Automatically created by Oracle when you run a SQL statement (e.g., `INSERT`, `UPDATE`, `DELETE`, `SELECT INTO`).
- **Explicit Cursor** – Manually declared by developers for processing multi-row query results.

---

### ⚙️ IMPLICIT CURSORS

#### ✅ When used:
- For simple, single-row DML statements (INSERT, UPDATE, DELETE, SELECT INTO).
- Oracle automatically manages them.

#### ✅ Common attributes:
| Attribute        | Description |
|------------------|-------------|
| `SQL%FOUND`      | TRUE if one or more rows were affected/fetched. |
| `SQL%NOTFOUND`   | TRUE if no rows were affected/fetched. |
| `SQL%ROWCOUNT`   | Returns the number of rows affected. |
| `SQL%ISOPEN`     | Always FALSE for implicit cursors. |

#### ✅ Example:
```sql
BEGIN
  DELETE FROM employees WHERE department_id = 10;
  IF SQL%FOUND THEN
    DBMS_OUTPUT.PUT_LINE('Employees deleted: ' || SQL%ROWCOUNT);
  ELSE
    DBMS_OUTPUT.PUT_LINE('No employees found for deletion.');
  END IF;
END;
```

---

### ⚙️ EXPLICIT CURSORS

#### ✅ When used:
- When a `SELECT` statement returns **multiple rows**.
- You want to process each row **individually**.

#### ✅ Lifecycle:
1. **DECLARE** the cursor
2. **OPEN** the cursor
3. **FETCH** rows from the cursor into variables
4. **CLOSE** the cursor

#### ✅ Example:
```sql
DECLARE
  CURSOR emp_cursor IS SELECT emp_id, emp_name FROM employees;
  v_id employees.emp_id%TYPE;
  v_name employees.emp_name%TYPE;
BEGIN
  OPEN emp_cursor;
  LOOP
    FETCH emp_cursor INTO v_id, v_name;
    EXIT WHEN emp_cursor%NOTFOUND;
    DBMS_OUTPUT.PUT_LINE('ID: ' || v_id || ', Name: ' || v_name);
  END LOOP;
  CLOSE emp_cursor;
END;
```

---

### 🔁 CURSOR FOR LOOPS

A **cursor FOR loop** simplifies the process:
- Automatically opens, fetches, and closes the cursor.

```sql
FOR emp_rec IN (SELECT emp_id, emp_name FROM employees) LOOP
  DBMS_OUTPUT.PUT_LINE('ID: ' || emp_rec.emp_id || ', Name: ' || emp_rec.emp_name);
END LOOP;
```

---

### 💡 REF CURSORS

- Used for **dynamic SQL** or **procedures/functions** that return query results.
- More flexible; query can be determined at runtime.

```sql
FUNCTION get_employees RETURN SYS_REFCURSOR IS
  emp_cursor SYS_REFCURSOR;
BEGIN
  OPEN emp_cursor FOR SELECT * FROM employees;
  RETURN emp_cursor;
END;
```

### ✅ **Assignment: Retrieve Allowance Details (Implicit Cursor)**

#### 📝 Requirement:
- Use `SELECT INTO` with proper handling for:
  - One row
  - No rows
  - Too many rows

#### ✅ Solution:
```sql
DECLARE
  v_allowance_id      ALLOWANCES.ALLOWANCE_ID%TYPE;
  v_allowance_amount  ALLOWANCES.ALLOWANCE_AMOUNT%TYPE;
  v_effective_date    ALLOWANCES.EFFECTIVE_DATE%TYPE;
  v_role_id           EMPLOYEES.ROLE_ID%TYPE;
BEGIN
  SELECT role_id INTO v_role_id FROM employees WHERE department_id = 2 AND ROWNUM = 1;

  SELECT allowance_id, allowance_amount, effective_date
  INTO v_allowance_id, v_allowance_amount, v_effective_date
  FROM allowances
  WHERE role_id = v_role_id;

  DBMS_OUTPUT.PUT_LINE('Allowance ID: ' || v_allowance_id);
  DBMS_OUTPUT.PUT_LINE('Amount: ' || v_allowance_amount);
  DBMS_OUTPUT.PUT_LINE('Effective Date: ' || TO_CHAR(v_effective_date, 'YYYY-MM-DD'));
EXCEPTION
  WHEN NO_DATA_FOUND THEN
    DBMS_OUTPUT.PUT_LINE('No allowance found.');
  WHEN TOO_MANY_ROWS THEN
    DBMS_OUTPUT.PUT_LINE('Too many allowances found.');
  WHEN OTHERS THEN
    DBMS_OUTPUT.PUT_LINE('Error: ' || SQLERRM);
END;
```

### ✅ **Assignment: Get Salary Stats (Function + SQL%ROWCOUNT)**

#### 📝 Requirement:
- Calculate:
  - Total salary
  - Average salary
  - Number of employees above a salary threshold

#### ✅ Solution:
```sql
CREATE OR REPLACE PROCEDURE get_salary_statistics(
  p_dept_id NUMBER,
  p_start_date DATE,
  p_end_date DATE,
  p_threshold NUMBER
) IS
  v_total NUMBER;
  v_avg   NUMBER;
  v_count NUMBER;
BEGIN
  SELECT NVL(SUM(salary), 0) INTO v_total
  FROM employees
  WHERE department_id = p_dept_id AND hire_date BETWEEN p_start_date AND p_end_date;

  SELECT NVL(AVG(salary), 0) INTO v_avg
  FROM employees
  WHERE department_id = p_dept_id AND hire_date BETWEEN p_start_date AND p_end_date;

  SELECT COUNT(*) INTO v_count
  FROM employees
  WHERE department_id = p_dept_id AND salary > p_threshold;

  DBMS_OUTPUT.PUT_LINE('Total Salary: ' || v_total);
  DBMS_OUTPUT.PUT_LINE('Average Salary: ' || v_avg);
  DBMS_OUTPUT.PUT_LINE('Employees Above Threshold: ' || v_count);
END;
```

### ✅ **Assignment: BULK COLLECT + FORALL**

#### 📝 Use case:
- Fetch all employees and give them a 10% raise using `BULK COLLECT` and `FORALL`.

#### ✅ Solution:
```sql
DECLARE
  TYPE emp_table IS TABLE OF employees%ROWTYPE;
  emp_data emp_table;

  TYPE num_table IS TABLE OF NUMBER;
  updated_ids num_table;
BEGIN
  SELECT * BULK COLLECT INTO emp_data FROM employees;

  FORALL i IN emp_data.FIRST .. emp_data.LAST
    UPDATE employees
    SET salary = salary * 1.10
    WHERE employee_id = emp_data(i).employee_id
    RETURNING employee_id BULK COLLECT INTO updated_ids;

  DBMS_OUTPUT.PUT_LINE('Updated ' || updated_ids.COUNT || ' employees.');
END;
```

### ✅ **Assignment: Return Annual Salary as Cursor (Function)**

#### 📝 Return for each employee:
- Full name
- Monthly salary
- Annual salary

#### ✅ Function:
```sql
CREATE OR REPLACE FUNCTION get_annual_salary(p_dept_id NUMBER)
RETURN SYS_REFCURSOR IS
  emp_cursor SYS_REFCURSOR;
BEGIN
  OPEN emp_cursor FOR
    SELECT first_name || ' ' || last_name AS full_name,
           salary,
           salary * 12 AS annual_salary
    FROM employees
    WHERE department_id = p_dept_id;

  RETURN emp_cursor;
END;
```

#### ✅ Anonymous Block:
```sql
DECLARE
  v_cursor SYS_REFCURSOR;
  v_name VARCHAR2(100);
  v_salary NUMBER;
  v_annual NUMBER;
BEGIN
  v_cursor := get_annual_salary(3);
  LOOP
    FETCH v_cursor INTO v_name, v_salary, v_annual;
    EXIT WHEN v_cursor%NOTFOUND;
    DBMS_OUTPUT.PUT_LINE(v_name || ' earns ' || v_salary || '/month and ' || v_annual || '/year');
  END LOOP;
  CLOSE v_cursor;
END;
```

### ✅ **Assignment: Use `BULK COLLECT + SQL%BULK_EXCEPTIONS`**

#### 📝 Use case:
- Insert many employees, handle and display errors without stopping the operation.

#### ✅ Solution:
```sql
DECLARE
  TYPE emp_ids IS TABLE OF NUMBER;
  ids emp_ids := emp_ids(101, 102, 103, 104);  -- 101, 103 might already exist
  errors NUMBER;
BEGIN
  FORALL i IN ids.FIRST .. ids.LAST SAVE EXCEPTIONS
    INSERT INTO employees (employee_id, salary) VALUES (ids(i), 5000);

EXCEPTION
  WHEN OTHERS THEN
    errors := SQL%BULK_EXCEPTIONS.COUNT;
    DBMS_OUTPUT.PUT_LINE('Number of errors: ' || errors);
    FOR i IN 1 .. errors LOOP
      DBMS_OUTPUT.PUT_LINE('Error at index ' || SQL%BULK_EXCEPTIONS(i).ERROR_INDEX ||
                           ' Code: ' || SQL%BULK_EXCEPTIONS(i).ERROR_CODE);
    END LOOP;
END;
```
